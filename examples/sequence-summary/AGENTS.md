# Sequence summary Agent

For FASTA summaries, read `.agents/skills/sequence-summary/SKILL.md` and use the
existing Python script through the Bash tool. Work from this project directory.
Save `summary.json` in the output directory specified in the task, and name the
input file in your response. Do not edit the input data or checker to make a run
pass. Leave `run.json` and `check.json` to the host.

These are synthetic teaching sequences. Sequence length is not a prediction of
protein structure, function, activity or experimental suitability.
